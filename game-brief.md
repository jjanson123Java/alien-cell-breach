# Alien: Cell Breach — Game Brief

Version: 1.0.0  
Audience: Adult fans of tense science-fiction horror; no graphic gore.

## Concept

Alien: Cell Breach turns every square of tic-tac-toe into a short Xenomorph encounter. Choose an empty chamber, counter the alien's deterministic attack, and earn an X when you survive; a failed encounter gives the alien an O.

## Player experience

- Main action: choose a grid cell, then select Shield, Blast, or Dodge.
- Round length: each battle resolves in two exchanges; the full match ends at a three-cell line or a filled grid.
- Outcome: three X marks wins, three O marks loses, and a full board without a line draws.
- Controls: mouse, touch, or keyboard Tab plus Enter/Space.
- Replay: Play again and Restart game both create a clean board.

## Completion checks

1. Start reveals an empty, selectable 3×3 grid.
2. Shield then Blast awards exactly one X; Blast then Shield awards exactly one O.
3. Board wins, losses, and draws resolve immediately after a cell is awarded.
4. Help explains every counter and returns without changing the current match.
5. Restart clears the board, active encounter, health, and exchange state.

## Scope and exclusions

This is an unofficial, noncommercial classroom fan project inspired by the *Alien* franchise. It uses original CSS and canvas artwork—no downloaded franchise artwork, film stills, logos, audio, accounts, backend, remote scores, purchases, framework, package dependency, or deployment.
